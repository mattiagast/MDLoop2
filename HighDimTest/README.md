# High-Dimensional Framework

The development of the high-dimensional extension of MDLoop2, integrating Symbolic-SINDy with convolutional autoencoders for latent-space model discovery, is continued in a separate repository:

**[HDSymbolicSINDy](https://github.com/mattiagast/HDSymbolicSINDy)**

The separation into an independent repository was introduced to ensure compatibility across different Python versions and dependency environments, allowing the high-dimensional framework to evolve independently while building upon the core MDLoop2 implementation.
